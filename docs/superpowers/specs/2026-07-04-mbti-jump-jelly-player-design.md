# MBTI Jump — 主角改晶亮果凍水滴＋速度驅動動感 設計文件

- 日期：2026-07-04
- 狀態：已通過 brainstorm（視覺 companion 比較後選定變體 A），待寫實作計畫
- 背景：主角演化史——黃色方塊 → 百變怪風紫色不定形團 → P2 白色基底（隨維度染成你的型別色）。但白色不定形團讀起來像「白包子」、扁平無質感；且跳躍動態只有落地那一下。使用者要更適合白色、且跳躍時有果凍動感的形象。

## 一句話描述

主角材質重繪為「晶亮果凍水滴」（大高光＋邊光＋底陰影＋暗邊，白色與染色都成立），跳躍改為每幀依垂直速度拉伸/壓扁的全速度驅動果凍動畫，開始頁與結果頁加落地投影。

## 設計決策

### 核心原則
- 所有明暗**相對於身體色**：高光用白 alpha、陰影/暗邊用黑 alpha，眼嘴用固定深墨色。→ 同一繪製函式對白基底與任一染色都成立。
- 碰撞體 36×36、混色機制（`PLAYER_BASE_COLOR = 0xf0f0f4`、`playerColorFor`）、玩法參數一律不動。

### 1. 材質（`ensurePlayerTexture` 重寫）
- texture 放大至 **54×50**（現 48×44）以容納高光與上緣邊光；碰撞體不變。
- 繪製順序（Phaser Graphics）：
  1. 身體：圓潤水滴橢圓（收斂為單一橢圓為主體，比舊版多圓凸團更像一顆果凍），填 `bodyColor`。
  2. 底部半月陰影：黑 10% 橢圓壓下緣（體積）。
  3. 柔和暗邊：極細（~1px）低透明黑描邊（亮背景上仍分得出輪廓）。
  4. 主高光：左上白 85% 柔和橢圓；右上白 90% 小閃點。
  5. 邊光：上緣一道細白弧（白 ~20%，線寬約身體半徑 0.12），給透亮玻璃/水珠光澤。
  6. 臉：兩點深墨色眼（`0x2a2340`）＋寬淺微笑弧（沿用招牌憨笑，維持角色連續性）。
- texture key 仍依色值快取（`player-proc-<hex>`）。

### 2. 全速度驅動果凍動畫（`Player` ＋ `GameScene`）
- 每幀（GameScene.update 呼叫 `player.tickJelly()`）依 `body.velocity.y` 更新變形：
  - 空中：`stretch = clamp(|vy| * k, 0, MAX)`；目標 `scaleY = 1 + stretch`、`scaleX = 1 / scaleY`（保體積）；當前 scale 以 lerp 平滑趨近目標，頂點（vy≈0）自然回圓。
  - 水平傾斜：依 `velocity.x` 給小幅 rotation lean（上限約 ±0.12 rad）。
- 落地衝擊（`bounce()`）：設壓扁 `setScale(1.35, 0.68)` 起點＋開啟 jiggle 計時；jiggle 期間（~420ms）用阻尼餘弦覆蓋 scale（回到 1），計時結束後恢復速度驅動。tickJelly 在 jiggle 期間讓位給 jiggle。
- reduced-motion：`tickJelly`/`bounce` 的變形全部略過，維持 scale 1（比照現行）。
- 具體常數（k、MAX、jiggle 曲線係數）於實作計畫定值；此處定行為。

### 3. 落地投影（grounding）
- 新增可選投影繪製：一顆柔和黑橢圓（黑 ~28%），畫在主角下方地面位置、depth 低於主角。
- **開始頁 hero**：hero 下方靜態投影（隨 hero 呼吸微幅縮放或固定皆可，實作計畫定）。
- **結果頁**：果凍最終色下方靜態投影。
- **遊戲中不加**：無限爬塔、主角幾乎全程在空中、下方平台持續捲動，固定偏移的陰影會變「浮空陰影」；遊戲中可讀性交給材質暗邊＋底陰影（P0 已調暗極光＋深色 HUD 卡）。

### 4. 貫穿
- 開始頁 hero、遊戲中、結果頁最終色皆走同一 `ensurePlayerTexture`，材質自動一致。
- 分享卡／OG 上無主角，不受影響。

## 明確不做（YAGNI）

- 粒子拖尾／殘影、表情切換、B 變體的雙高光全套。
- 遊戲中動態地面陰影（浮空陰影問題）。
- 混色公式、基底色、玩法參數變動。

## 測試與驗證

- 純視覺/動畫，無新純函式；既有測試全綠、`tsc --noEmit` 乾淨。
- 若把「速度→目標 scale」的映射抽成純函式（如 `jellyScaleForVelocity(vy)`），加單元測試（vy=0 回 1、大 |vy| 拉長且保體積、封頂）。
- 截圖驗收：開始頁 hero（白水滴＋投影＋邊光）、遊戲中跳躍（形狀；動感靠實玩／連續截圖）、結果頁最終色水滴＋投影；抽查一張染色態（如 INFP 綠）確認高光/邊光在染色上仍讀得出。

## 驗收標準

1. 主角一眼是「晶亮果凍水滴」，有體積與光澤，不再像扁平白包子。
2. 跳躍時明顯拉伸/壓扁＋落地晃動，果凍動感足。
3. 白色與四關染色態都好看（高光/邊光/暗邊相對身體色成立）。
4. 開始頁/結果頁有落地投影，白角色不再浮在深底上。
5. reduced-motion 下靜態呈現、功能不缺；玩法與碰撞不變。
