# MBTI Jump — P0 遊戲內可讀性包 設計文件

- 日期：2026-07-02
- 狀態：已通過 brainstorm（使用者授權採推薦值定案），待寫實作計畫
- 背景：UI/UX 審查（ui-ux-pro-max ＋ 實機截圖）發現遊戲場景「圖底分離」不足：台階、答案預覽、題目、得分條字母全部浮在亮色極光背景上，對比與可讀性不達標。本包只處理可讀性，不動玩法、不動佈局結構、不做 juice（粒子/combo 屬 P1+）。

## 一句話描述

GameScene 的資訊層（HUD）加一體式深色底襯、答案預覽改實心膠囊 chip、台階材質加立體邊、得分條票數改字母色圓章、極光整體降亮 15%——五個純視覺改動，玩法與佈局座標不變。

## 現況（程式對照）

- 題目 banner：`GameScene.create()` y=40，白 24px 粗體＋黑描邊 4，無底襯。
- 關卡標籤：y=108，14px `#ffffffaa`。
- 得分條：`drawScoreBar()`，200×22 @ (125,128)，字母色雙向漸變＋白 3px 分隔線；票數文字 14px 白＋黑描邊在 x=135/315。
- 答案預覽：`previewLeft/Right`，17px 粗體、`letterHex` 字色＋黑描邊，y=158 貼左右緣，alpha 隨玩家與分叉距離長距離漸變（`update()` 內）。
- 普通台階：`Platform.ensureTextures()` 生成 `0x5d6b9e` 圓角矩形 texture（圓角 6）。
- 答案台階：中性白底 texture ＋ `setTint(LETTER_COLORS[side])`；標籤 18px 白＋黑描邊。
- 極光：`gfx/AuroraBackground.ts`，中心亮色由族群/維度色混白而來（本包只調此混白量）。

## 設計決策（五項）

### 1. HUD 一體式深色圓角卡
- 一塊 `PALETTE.surface`（0x1a1c2c）72% 不透明、**僅底部**圓角 16px 的矩形，覆蓋 x:0..GAME.width、y:0..154（154 = 得分條下緣 150 ＋分隔線超出量 2px ＋餘裕；頂部貼齊畫面邊，維持現有元素座標不動）。
- `setScrollFactor(0)`，depth 19（既有 HUD 元素 depth 20/21 之下、遊戲元素之上）。
- 題目 banner **移除黑描邊**（`stroke`/`strokeThickness` 拿掉）——有底襯後不需要；字級/字重/位置不變。
- 關卡標籤、得分條位置不變，收在卡內。

### 2. 答案預覽 → 實心膠囊 chip
- 左右各一組「膠囊底＋文字」：
  - 底：該答案字母色（`LETTER_COLORS[side]`）實心、圓角 12px、內距水平 10px / 垂直 6px，隨文字寬度自適應（wordWrap 上限維持 `GAME.width * 0.44`）。
  - 字：`PALETTE.textOn`（深色 #0f1220）17px 粗體，**移除黑描邊**；`◀`/`▶` 箭頭保留在文字內。
- 位置：貼左右緣（x=12 / GAME.width-12），y=158（HUD 卡下緣之下）不變。
- 淡入行為改變：不再用「距離長漸變」——進入提示範圍（現行 alpha>0 的同一觸發點）後以 **200ms 快速淡入至 1**；離開範圍（無下一分叉）同樣 200ms 淡出。reduced-motion：直接 setAlpha(1/0) 無過渡（比照現行為）。
- 實作註記：Phaser 下用 Graphics（或 generateTexture 膠囊）＋ Text 組成；chip 幾何（給定文字尺寸→膠囊 x/y/w/h）抽成純函式 `chipRect()` 進 `src/core/hud.ts` 供單測。

### 3. 台階材質立體化
- 普通台階：底色 `0x5d6b9e` → **`0x3d4a7a`**（深一階）；texture 內加頂邊 2px 亮線 `0x8fa0d8`、底部 3px 暗帶（黑 25% alpha）。圓角 6 不變。
- 答案台階中性底圖：白底 → 「白底＋頂邊 2px 更亮白（保持 tint 後成為亮色）＋底部 3px 暗帶」；tint 機制與標籤樣式（白字黑描邊）不變。
- 尺寸、碰撞體、`setDisplaySize` 拉伸邏輯全部不動（暗帶/亮線用相對比例繪製，拉伸後仍成立）。
- 最後一題金色標記不動。

### 4. 得分條字母章
- 兩端票數文字改為「字母色膠囊圓章＋深色（`textOn`）14px 粗體字」，如 `E 2`；膠囊圓角=高度/2、內距 8×3。
- 分隔線 3px → **5px**，頂端加直徑 8px 的白色圓頭旋鈕（圓形）。
- 漸變底、尺寸 200×22、位置 (125,128) 不變；`scoreBarModel` 純函式**不動**，僅 `drawScoreBar()` 繪製層改。

### 5. 極光降亮 15%
- `AuroraBackground` 內中心色混白量（tint-toward-white 的 amount 或等效常數）整體乘 0.85。只調亮度常數，不動動畫、飄移、reduced-motion 邏輯。

## 明確不做（YAGNI）

- 粒子、落地 juice、combo 音效（P1）。
- HUD/台階佈局座標與玩法參數改動。
- 開始頁/結果頁/趨勢/成就（P1/P2 包）。
- 新素材圖檔（全部程式繪製）。

## 測試與驗證

- 新純函式 `chipRect()`（文字尺寸→膠囊幾何）單元測試。
- 其餘為 Phaser 繪製，無純邏輯可抽者不硬測；以**瀏覽器截圖驗證**收尾：四個維度各截「題目＋預覽＋得分條」畫面，逐項對照本設計（底襯存在、chip 可讀、台階浮起、圓章對比、極光仍有氛圍）。
- 既有 116 測試全綠、`tsc --noEmit` 乾淨。

## 驗收標準

1. 題目、關卡、得分條在四個維度背景下均清晰可讀（深色底襯上白字）。
2. 答案 chip 在任何背景下全不透明可讀（字母色底＋深字）。
3. 台階與背景有明確圖底分離（亮線＋暗帶＋更深底色）。
4. 得分條兩端一眼可辨字母與票數。
5. 極光氛圍仍在（只降 15%，非關掉）。
